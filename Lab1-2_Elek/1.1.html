HTML (HyperText Markup Language) — це стандартна мова розмітки для створення вебсторінок, яка визначає їх структуру та вміст. Гіпертекст дозволяє пов’язувати документи між собою за допомогою посилань, формуючи взаємопов’язану мережу сторінок.

Початок історії HTML пов’язаний із Тімом Бернерсом-Лі, співробітником CERN, який у 1989 році розробив першу версію мови. У 1991 році HTML почали використовувати лише для науки почали використовувати для передачі гіпертексту в Інтернеті.

Сучасний HTML значно еволюціонував: від простих текстових сторінок до складних вебзастосунків. Незважаючи на розвиток технологій, HTML залишається фундаментом веброзробки.
